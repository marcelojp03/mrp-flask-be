
INSTRUCCIONES PARA LEVANTAR EL BACKEND (Windows PowerShell)

Requisitos previos:
- Python 3.10+ instalado y accesible desde la terminal (`python`)
- PostgreSQL disponible y usuario con permisos para crear bases de datos

1) Crear la base de datos en PostgreSQL
- Conéctate a PostgreSQL y crea la base de datos que usa la aplicación (ejemplo `dbinf342`):

```powershell
# Acceder al prompt de postgres (te solicitará contraseña del usuario postgres)
psql -U postgres
# Dentro de psql:
CREATE DATABASE dbinf342;
\q
```

Alternativamente (desde PowerShell, si tienes `createdb` disponible):

```powershell
createdb -U postgres dbinf342
```

2) Crear y activar un entorno virtual (Windows PowerShell)

```powershell
# En la raíz del proyecto
python -m venv env
.\env\Scripts\Activate.ps1
```

Si PowerShell lanza un error de ejecución (política de scripts), ejecutar como usuario:

```powershell
Get-ExecutionPolicy -List
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
```

3) Instalar dependencias

```powershell
pip install -r requirements.txt
```

Importante: asegúrate de tener `psycopg2-binary` (o `psycopg2`) en `requirements.txt` para la conexión con PostgreSQL.

4) Configurar variables de entorno / ajustar `app/config.py` (según tu entorno)

- La aplicación usa `app.config.Config`. Revisa `app/config.py` y asegúrate de que la cadena de conexión a la base de datos (`SQLALCHEMY_DATABASE_URI`) apunte a la base que creaste.
- Alternativamente puedes exportar la variable de entorno `DATABASE_URL` o la que tu `Config` espera. Ejemplo (PowerShell) usando `psycopg2`:

```powershell
$env:DATABASE_URL = 'postgresql+psycopg2://usuario:password@localhost:5432/dbinf342'
```

5) Crear tablas y ejecutar la aplicación

El archivo principal es `myapp.py` y crea las tablas automáticamente en `db.create_all()` cuando se registra el app context.

```powershell
# Desde la raíz del proyecto con el venv activado
python myapp.py
```

La aplicación arrancará en `http://0.0.0.0:8585` (puedes abrir `http://localhost:8585`).

6) Comprobaciones y problemas comunes
- Si faltan paquetes, revisa `requirements.txt` y reinstala: `pip install -r requirements.txt`.
- Si hay errores de import al arrancar, verifica que `env` esté activado y que `PYTHONPATH` no esté interfiriendo.
- Si la app no puede conectarse a PostgreSQL, verifica las credenciales y que el servicio esté en ejecución (`sudo service postgresql status` o desde el panel de servicios en Windows).

7) Comandos útiles

```powershell
# Crear/actualizar virtualenv
python -m venv env
.\env\Scripts\Activate.ps1
pip install -r requirements.txt

# Establecer variable de entorno temporalmente y ejecutar la app
$env:DATABASE_URL = 'postgresql+psycopg2://usuario:password@localhost:5432/dbinf342'
python myapp.py
```

Notas:
- El proyecto crea las tablas con SQLAlchemy `db.create_all()` al arrancar; para producción utiliza migraciones (Flask-Migrate/Alembic).
- Si vas a usar Docker, revisa `Dockerfile` y `docker-compose.yml` para orquestar la base de datos y la app.
